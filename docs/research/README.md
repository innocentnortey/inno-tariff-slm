## Provenance and limits

Imported files are unchanged snapshots, not automatically synchronized copies. [The source manifest](source-manifest.json) records each original location and SHA-256 checksum. Update deliberately and keep the import date and manifest current when refreshing them. The original brief PDF is authoritative over its Markdown conversion.

Historical documents retain their original dates, paths, claims, and estimates. Some links name the original Gauntlet workspace; use this index to locate project-local equivalents. Broad alternative-domain material and generator inputs are retained as research context, not adopted project requirements. The earlier idea explorer is a standalone snapshot; its separate rebuild inputs are not included. The large slide PDF and slide images are not copied; the searchable slide text is included.

No datasets, model weights, or CBP ruling corpus were copied. No new model experiment was run by importing these documents.
