What I built

Real rulings in, one checked answer out

Data

27,841 CBP rulings. Each product described in CBP's own words, with every sentence that names the code removed. Labels only from CBP and the schedule.

Search

Keyword plus meaning-based search over earlier rulings and the full schedule. Only rulings issued before the product are visible.

Model

Qwen3-4B fine-tuned with LoRA on Modal, three training runs. Runs on one GPU and answers in about a second.

Honest test

500 rulings CBP issued Aug 2025 – Oct 2026, after all training data. Protocol frozen before any tuned model was scored.
